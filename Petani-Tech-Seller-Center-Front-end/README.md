# Petani Tech Seller

React Native app built with Expo, TypeScript, and React Navigation.

## Start the app

```sh
npm install
npx expo start
```

Open the project in Expo Go or a native development build. Use `npm run typecheck` to check TypeScript.

The demo account is `seller@petanitech.id` with password `123456`. The session is stored on-device using AsyncStorage.

## API configuration

Copy `.env.example` to `.env` and set `EXPO_PUBLIC_API_URL` if using a backend. `EXPO_PUBLIC_USE_MOCK` defaults to `true`.
